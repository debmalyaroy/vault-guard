Threat Ledger — Semantic Intelligence

BoltDB-backed threat corpus storing 540+ OWASP Agentic Top 10 patterns with binary float32 embeddings. New threats learned at runtime — the corpus grows as attackers evolve.

  • 540+ pre-seeded patterns across 10 OWASP categories
  • 1024-dimensional Titan Embed Text v2 vectors
  • Binary storage: 4KB per pattern vs 15KB JSON
  • In-memory cosine similarity — zero DB query overhead
  • Novel threats auto-added after LLM confirmation
  • Timeseries analytics per session and global
// BoltDB bucket schema
// corpus_meta/{id} → JSON(ThreatMeta)
// corpus_embed/{id} → []byte(float32×1024)
// Similarity search
emb = TitanEmbed(payload)
all = bolt.GetAll("corpus_embed")
for id, vec := range all {
  sim = CosineSimilarity(emb, vec)
  if sim > 0.92 → REDACTED
}
Latency: ~0.3ms (in-process, no network)
